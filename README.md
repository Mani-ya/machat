## 🇮🇷 فارسی

### 🌟 درباره پروژه

**چت خصوصی** یک پیام‌رسان تحت وب سبک و کاملاً رایگان است که روی **GitHub Pages** میزبانی می‌شود و از **Supabase** به‌عنوان بک‌اند استفاده می‌کند. این پروژه برای گروه‌های کوچک (۴ تا ۱۵ نفر) طراحی شده و نیازی به سرور اختصاصی ندارد.

پیام‌های آنلاین از طریق **WebSocket (Broadcast)** مستقیماً بین کاربران رد و بدل می‌شوند و **از دیتابیس عبور نمی‌کنند**. تنها پیام‌هایی که طرف مقابل آفلاین است در دیتابیس ذخیره می‌شوند تا هنگام آنلاین شدن تحویل داده شوند و سپس حذف گردند.

🌟 About
Private Chat is a lightweight, completely free web messenger that runs on GitHub Pages and uses Supabase as its backend. It's designed for small groups (4–15 users) and requires no dedicated server.

Online messages are exchanged directly between users via WebSocket (Broadcast) and never pass through the database. Only messages destined for offline users are stored in the database, delivered when the recipient comes online, and then deleted.
